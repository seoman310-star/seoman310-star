# On-Page SEO Audit

A practical on-page SEO audit focused on improving page relevance, content structure, user experience, and search-engine understanding.

> **Project Type:** Sample / Practice SEO Project

## 🎯 Objective

The objective of this audit is to identify on-page SEO issues and provide actionable recommendations for improving individual website pages.

## 🔍 Areas Audited

### 1. Title Tags
Checked:
- Keyword relevance
- Title length
- Search intent
- Duplicate titles

### 2. Meta Descriptions
Checked:
- Relevance to page content
- Search intent
- Keyword usage
- Click-through potential

### 3. Heading Structure
Reviewed:
- H1 usage
- H2 and H3 structure
- Content hierarchy
- Keyword relevance

### 4. URL Structure
Checked:
- URL readability
- Keyword relevance
- Unnecessary parameters
- URL consistency

### 5. Content Optimization
Reviewed:
- Search intent
- Keyword usage
- Content relevance
- Content structure
- Readability

### 6. Internal Linking
Checked:
- Relevant internal links
- Anchor text
- Important pages
- Link distribution

### 7. Image Optimization
Checked:
- Image ALT text
- File names
- Image relevance
- Basic optimization opportunities

## 📊 Priority Levels

| Priority | Meaning |
|---|---|
| 🔴 High | Important issue requiring attention |
| 🟠 Medium | Should be improved |
| 🟢 Low | Recommended improvement |

## 🛠️ Recommended Actions

- Optimize title tags
- Improve meta descriptions
- Create a clear heading hierarchy
- Optimize URLs
- Align content with search intent
- Improve internal linking
- Optimize image ALT text
- Improve overall content structure

## 🧰 Tools Used

- Google Search Console
- Ahrefs
- Semrush
- Screaming Frog
- Google Search

## 📌 Key Takeaway

Effective on-page SEO helps search engines understand a page while providing users with relevant and useful content.

This project demonstrates my approach to identifying on-page SEO issues and creating practical recommendations.
