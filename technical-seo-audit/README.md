# Technical SEO Audit

A practical technical SEO audit focused on identifying website issues that can affect crawling, indexing, search visibility, and overall SEO performance.

> **Project Type:** Sample / Practice SEO Audit

## 🎯 Objective

The objective of this audit is to identify important technical SEO issues and provide clear, actionable recommendations to improve a website's search-engine accessibility and technical health.

## 🔍 Areas Audited

### 1. Crawlability

Checked whether search-engine crawlers can properly access important website pages.

**Key checks:**

* Robots.txt
* Crawl directives
* Internal links
* Blocked resources
* Crawl errors

### 2. Indexability

Reviewed whether important pages can be discovered and indexed by search engines.

**Key checks:**

* Noindex tags
* Indexing directives
* Canonical tags
* Duplicate pages
* Index coverage

### 3. XML Sitemap

Reviewed the XML sitemap for:

* Valid URLs
* Indexable pages
* Incorrect URLs
* Missing important pages
* Sitemap accessibility

### 4. Robots.txt

Checked the robots.txt file for:

* Correct syntax
* Unnecessary blocked sections
* Important pages being blocked
* Sitemap reference

### 5. Canonical Tags

Reviewed canonical implementation to identify:

* Missing canonical tags
* Incorrect canonical URLs
* Duplicate-page issues
* Self-referencing canonicals

### 6. Broken Links

Checked internal links for:

* 404 pages
* Redirect chains
* Broken internal URLs
* Incorrect redirects

### 7. Site Structure

Reviewed the website structure and internal linking to determine whether important pages are easily accessible.

### 8. Mobile SEO

Checked mobile usability and whether the website provides a suitable experience for mobile users.

### 9. Page Speed

Reviewed page-performance factors that may affect user experience and search performance.

### 10. HTTPS & Security

Checked whether the website properly uses HTTPS and whether HTTP versions redirect correctly to HTTPS.

| Priority  | Meaning                                                     |

## 🛠️ Recommended Actions

The audit recommendations focus on:

* Improving crawlability
* Improving indexability
* Fixing broken links
* Correcting canonical implementation
* Optimizing robots.txt
* Maintaining a clean XML sitemap
* Improving internal linking
* Improving mobile usability
* Improving page performance
